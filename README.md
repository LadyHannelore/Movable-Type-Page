# Movable Type Page 

Renders entered text as a parchment-style page with a border and a little randomized ink variation, animated like a movable type printing press.

## Features
- Parchment page with a woven-style border and aged shading.
- Per-character ink variation: opacity, tone, tilt, size and bleed.
- Typesetting animation: each character drops in like a slug of type being set.
- Press animation: a platen presses down over the page, which thumps slightly.
- Live updates as you type.

## Usage
No build or dependencies needed. Open `index.html` in a browser, then:
- Type in the text box to update the page.
- **Print** replays the typesetting and press animation (also plays on load).
- **Re-ink** re-rolls the random ink variation.
- **Variation** slider controls how strong the ink variation is.
